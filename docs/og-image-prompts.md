# Open Graph image prompts

The shipped cards are static PNGs in `public/og/{slug}.png` (1200 × 630). These prompts are for regenerating them with an image tool. Attach the logo as Image A; for the avatar card attach `public/avatars/state-idle-blue.png` as Image B. The existing logo has a baked-in checkerboard; replace it with a transparent master when available.

## Master prompt

```text
Create a modern editorial Open Graph image for “Grok Bot Explained”.
Canvas: exactly 1200 × 630.
Use attached Image A as the site logo, unchanged, small and clear at top-left with generous clear space. Use it once, never centered or as a watermark. Use a clean transparent master when available.
White or off-white background; black typography; restrained electric-blue accents. Strong bold modern sans-serif headlines, clean supporting type, crisp alignment, generous negative space. Calm, friendly and highly legible at social preview size.
Headline on the left, supporting text beneath, page-specific visual on the right. Keep a consistent grid across all seven cards.
No gradients, glassmorphism, 3D additions, stock imagery, generic robots, fake dashboards, clutter, neon effects or advertisement styling.
```
